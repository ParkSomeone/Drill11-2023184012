# AUTO_RUN 개발 명세서

## 1. 개발 목적

소년(Boy)의 상태에 자동 달리기 상태 `AUTO_RUN`을 추가한다. `AUTO_RUN` 상태에서 소년은 바라보는 방향으로 자동 이동하며, 시간이 지날수록 이동 속도와 표시 크기가 증가한다.

## 2. 구현 범위 및 제약

- 기존 `boy.py`의 `Boy` 클래스와 상태 머신을 확장한다.
- 필요한 경우에만 `main.py`를 수정한다.
- 새 소스 파일이나 모듈을 추가하지 않는다.
- 상태 이름은 실제 코드에서 `AUTO_RUN`을 사용하고, 이 문서에서는 편의상 `A` 상태라고 부른다.
- 별도의 모듈을 추가하지 않고 현재 프로젝트의 의존성과 코딩 패턴을 따른다.

## 3. 상태 전이

| 현재 상태    | 입력/조건        | 다음 상태    | 동작                                                              |
| ------------ | ---------------- | ------------ | ----------------------------------------------------------------- |
| `IDLE`     | `a` 키 입력    | `AUTO_RUN` | 자동 달리기를 시작하고 경과 시간을 초기화한다.                    |
| `AUTO_RUN` | 좌우 방향키 입력 | `RUN`      | 입력된 방향으로 일반 달리기를 시작한다. 속도와 크기를 초기화한다. |
| `AUTO_RUN` | 시작 후 5초 경과 | `IDLE`     | 자동 달리기를 종료하고 속도와 크기를 초기화한다.                  |
| `AUTO_RUN` | 그 외            | `AUTO_RUN` | 현재 바라보는 방향으로 자동 이동하며 속도와 크기를 증가시킨다.    |

`a` 키는 `IDLE` 상태에서만 자동 달리기를 시작한다. `AUTO_RUN` 중에는 현재 얼굴 방향(`face_dir`)을 유지하며 이동한다. 방향키가 눌리면 기존 달리기 입력 처리와 일관되게 해당 방향을 바라보고 `RUN` 상태로 전환한다.

## 4. 속도와 크기 증가 규칙

기존 `RUN`의 기본 이동량인 **업데이트 1회당 5픽셀**을 자동 달리기의 시작 속도로 사용한다. 자동 달리기 시작 후 경과 시간을 기준으로 다음과 같이 증가시킨다.

- 시작 속도: 업데이트 1회당 **5픽셀**
- 속도 증가량: 경과 시간 **1초당 업데이트 1회당 0.5픽셀**
- 시작 표시 크기: **100 × 100픽셀**
- 크기 증가량: 경과 시간 **1초당 가로·세로 각각 10픽셀**
- 최대 지속 시간: **5초**

자동 달리기 시작 후 `t`초가 경과했을 때의 값:

- 이동량: 업데이트 1회당 `5 + (0.5 × t)`픽셀
- 표시 크기: `(100 + 10 × t) × (100 + 10 × t)`픽셀

따라서 5초 시점의 속도는 업데이트 1회당 7.5픽셀, 표시 크기는 150 × 150픽셀이다. 증가는 상태 시작 시각을 기준으로 계산하며, 게임 루프 업데이트 횟수에 직접 비례하는 누적 방식은 사용하지 않는다. 기존 게임 루프의 프레임 간격에 따라 초당 실제 이동 거리는 달라질 수 있다.

## 5. 초기화 및 기존 동작 유지

- `AUTO_RUN` 진입 시 시작 시각을 기록하고 속도와 크기를 시작값으로 설정한다.
- `AUTO_RUN`에서 `IDLE` 또는 `RUN`으로 나갈 때 자동 달리기의 속도·크기 값을 초기화해 다음 상태에 영향을 주지 않게 한다.
- `RUN`의 기존 이동 동작, `IDLE`의 애니메이션과 수면 전환, `SLEEP`의 기상 동작은 변경하지 않는다.
- 기존 `IDLE` 자동 수면 타이머가 자동 달리기 진행 중 상태를 바꾸지 않도록 한다. 자동 달리기 종료 후 `IDLE`에 진입하면 기존 타이머 동작을 유지한다.

## 6. 검증 기준

1. `IDLE`에서 `a` 키를 누르면 `AUTO_RUN`으로 전환된다.
2. `AUTO_RUN` 중에는 마지막으로 바라보던 방향으로 이동한다.
3. 속도는 시작값 5픽셀/업데이트에서 경과 1초마다 0.5픽셀/업데이트씩 증가한다.
4. 표시 크기는 100 × 100픽셀에서 경과 1초마다 가로·세로 각각 10픽셀씩 증가한다.
5. `AUTO_RUN`은 시작 후 5초가 지나면 `IDLE`로 돌아간다.
6. `AUTO_RUN` 중 좌우 방향키를 누르면 입력 방향의 `RUN` 상태가 된다.
7. 시간 만료와 방향키 전환 모두에서 자동 달리기의 속도·크기 증가 값이 초기화된다.
8. 기존 `RUN`, `IDLE`, `SLEEP` 동작에 회귀가 없다.

## 7. 개발 단계 및 커밋 계획

각 단계를 순서대로 구현하고 검증한다. 한 단계의 변경과 검증이 끝나면 해당 단계의 변경만 별도로 커밋한다. 다음 단계의 변경을 하나의 커밋에 섞지 않는다.

| 단계 | 개발 내용 | 단계 완료 기준 | 커밋 메시지 예시 |
|---|---|---|---|
| 1. 상태 및 전이 추가 | `AUTO_RUN` 상태와 `IDLE`에서 `a` 키로 진입하는 전이를 추가한다. 상태 진입 시각과 자동 달리기 초기값을 준비한다. | 키 입력으로 `IDLE`에서 `AUTO_RUN`으로 전환되고 기존 상태 전이가 유지된다. | `Add AUTO_RUN state and transition` |
| 2. 자동 달리기 동작 구현 | 바라보는 방향으로 이동시키고, 경과 시간에 따른 속도와 표시 크기 증가 및 5초 종료를 구현한다. | 증가 규칙과 종료 시점이 검증 기준에 맞는다. | `Implement AUTO_RUN movement and growth` |
| 3. 입력 전환 및 초기화 처리 | `AUTO_RUN` 중 방향키 입력 시 `RUN`으로 전환하고, `AUTO_RUN` 종료 시 증가값을 초기화한다. 기존 상태 동작과의 상호작용을 확인한다. | 방향키 전환, 초기화, 기존 `IDLE`·`RUN`·`SLEEP` 동작이 모두 검증된다. | `Handle AUTO_RUN exit and reset` |

커밋하기 전에는 해당 단계와 관련된 검증을 수행하고, 통과한 변경만 커밋한다. 각 커밋은 한 단계의 목적을 명확히 나타내도록 작성한다.
